Folder ini untuk video lagu (opsional).

  yalal-wathon.mp4   -> Mars Syubbanul Wathon

Kompres dengan HandBrake, preset "Fast 720p30".
Upload lewat browser GitHub dibatasi 25 MB per file.

Kalau file belum ada, tombol "Putar video di web" nonaktif dan
tombol YouTube tetap bisa dipakai. Hapus file ini bila sudah tidak perlu.
