# Aturan Rujukan Desain & Pewarnaan

Setiap kali menjalankan perintah, perencanaan, pembuatan, atau modifikasi antarmuka pengguna (UI/CSS/HTML/komponen visual), agen WAJIB selalu membaca dan mematuhi patokan sistem warna dan aturan desain di:
1. `desain.md` (dokumen panduan lengkap sistem warna, rasio kontras WCAG, dan filosofi desain)
2. `DESIGN.md` (definisi token warna CSS dan dial antislop)

Dilarang menggunakan warna atau gaya di luar token dan aturan yang telah ditetapkan di kedua file tersebut.
